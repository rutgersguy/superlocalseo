# Customer-facing review language

Use SuperLocalSEO and the service name in customer-facing copy. Do not display the review infrastructure vendor's name or acronym in customer screens, help text, status labels, or feedback exports. Technical identifiers, logs, and the operator-only mapping guide retain their existing names.

Explain private feedback as an optional message to the business, separate from a public Google review. Customers can use either option or both at any rating. The inbox helps account owners and admins assign follow-up, record internal notes, and track resolution; saving those changes does not send a customer message or publish a review. Contact customers only using details they consented to share. Explain missing historical feedback without implementation terms.

Review invitations are accepted for processing, not confirmed delivered. Explain send windows, opt-outs, duplicate protection, and how to contact SuperLocalSEO support about uncertain requests. Never ask a customer to inspect the vendor dashboard or contact the vendor.

Third-party data processing remains disclosed by service category in the privacy and terms pages. This copy change does not change data routing, collection, retention, consent, or review access.

Billing and reactivation use the shared BrandWordmark component, matching login and the dashboard.
